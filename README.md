# Mini ETL Project – Git Version Control & CI

## 📌 Project Overview

A mini ETL (Extract, Transform, Load) project built using Python to practice Git version control, branching, merging, automated testing, and Continuous Integration (CI) using GitHub Actions.

## 🛠️ Technologies Used

* **Python** – ETL script development
* **Git & GitHub** – Version control, branching, and merging
* **Pytest** – Automated testing
* **GitHub Actions** – Continuous Integration (CI)

## ⚙️ Key Features

* Extracts data from a CSV file.
* Transforms data by converting values into appropriate data types.
* Loads and displays the transformed data.
* Validates records to filter out invalid or empty values.
* Uses Git commits, feature branches, and merge conflict resolution.
* Runs automated tests using Pytest.
* Automatically executes tests through GitHub Actions when code is pushed or a pull request is created.


## 🎯 Learning Outcomes

* Practiced Git version control and commit management.
* Implemented branching, merging, and conflict resolution.
* Created automated tests using Pytest.
* Configured a GitHub Actions CI workflow.
